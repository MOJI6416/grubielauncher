Animated stickers in this folder are Noto Emoji Animation by Google,
retrieved on October 5, 2026 from https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/lottie.json
(catalog: https://googlefonts.github.io/noto-emoji-animation/).

License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

Changes: numeric values rounded to three decimal places to reduce file size.
The <codepoint>.webp files are still frames rendered from these animations
(128 px, the frame set by `rest` in features/stickers/catalog.ts) and are
shown until an animation is needed.
The launcher credits the set in the sticker picker.
